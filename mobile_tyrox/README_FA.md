# TYROX Mobile — Python foundation (0.4.0-dev)

این پوشه پایهٔ کلاینت اندروید TYROX با Python و Kivy است. در این مرحله، اتصال HTTPS با بررسی SHA-256 گواهی پیش از ارسال درخواست، احراز هویت Bearer، فهرست فایل‌ها، آپلود و دانلود در فضای خصوصی برنامه پیاده‌سازی شده است.

## اجرا روی دسکتاپ برای تست رابط

```bash
python -m pip install kivy
python main.py
```

## ساخت APK

Buildozer را روی Linux یا WSL2 نصب کن؛ سپس در همین پوشه:

```bash
buildozer android debug
```

خروجی معمولاً در `bin/` ساخته می‌شود. اولین ساخت به اینترنت و دانلود Android SDK/NDK نیاز دارد.

## اتصال

1. TYROX Desktop را روی ویندوز اجرا کن.
2. از بخش This computer مقدار Pairing token و اثرانگشت کامل SHA-256 را بردار.
3. IP کامپیوتر، پورت 47821، توکن و fingerprint را در موبایل وارد کن.
4. اگر آپلود در دسکتاپ غیرفعال است، صاحب کامپیوتر باید آن را از تنظیمات فعال کند.

## وضعیت فعلی و محدودیت‌ها

- فایل‌لیست، آپلود و دانلود از API موجود دسکتاپ استفاده می‌کنند.
- دانلود فعلاً در فضای خصوصی TYROX ذخیره می‌شود؛ انتخاب مسیر عمومی اندروید و Share/Export باید با Android Storage Access Framework اضافه شود.
- کشف UDP به مجوزها و رفتار multicast/broadcast شبکه و نسخه اندروید وابسته است؛ روی دستگاه واقعی باید آزمایش شود. در صورت شکست، IP دستی قابل استفاده است.
- استریم زنده و کنترل ماوس/کیبورد هنوز در این کلاینت پیاده‌سازی نشده‌اند. API دسکتاپ فعلی فقط مذاکرهٔ WebRTC برای مشاهدهٔ صفحه با تأیید کاربر را دارد؛ کنترل از راه دور نیازمند کانال ورودی جداگانه، UI تأیید و محدودسازی نشست است.
- قبل از انتشار، باید تست‌های شبکه، انتقال فایل بزرگ، قطع اتصال، خطاهای TLS و مجوزهای اندروید انجام شود.

## نکته امنیتی درباره TLS

کلاینت فقط پس از اتصال TLS و مقایسهٔ fingerprint گواهی با مقدار واردشده، درخواست HTTP را ارسال می‌کند. fingerprint را از کانال قابل اعتماد و روی خود کامپیوتر مقصد تطبیق بده؛ صرفاً به fingerprint دریافتی از شبکه اعتماد نکن.
